Privacy Policy

Last updated: 6 October 2026

F&B Stories Uploader ("the app") is a private tool operated by Edvyn Tanu ("I", "me") to upload my own original short videos to my own YouTube channel (https://www.youtube.com/channel/UCYSNc72tTCzn4qNhDA6eQSA). It is not offered to the public and has no other users.

YouTube API Services

The app uses YouTube API Services. By using the app you also agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the app accesses

The app requests these permissions for my own Google account only:

  • Upload videos (youtube.upload): to publish my videos to my channel.
  • View my YouTube account (youtube.readonly): only to confirm which channel it is logged in to.

The app does not access, collect or store any data about other YouTube users or viewers.

What data the app stores

  • An OAuth access/refresh token for my account, stored in a file on my private server that only the server's administrator account can read.
  • The videos I created and their titles, descriptions and upload results (video ID and link).

No data is sold, shared with third parties, or used for advertising.

Retention and deletion

The token is kept only while the app is in use. Deleting the token file on the server removes it immediately. Video files and records can be deleted from the server at any time.

Revoking access

Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions
